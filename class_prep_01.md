# Pick your own use case
Grab a pen and paper, or take notes on your computer or in your favourite AI tool. Think of a product you use or a task you'd like to automate. Write a prompt for it using the four elements:

# Element	Ask yourself
Role	
   What would be the role of this AI?
   
Task	
   What would you like it to do?
Constraints	What are you saying it should not do?
Format	How would you like it to output the answer?
These are the same four elements you complete for Juno. These elements for the skill file shape the deliverables in your final project.
